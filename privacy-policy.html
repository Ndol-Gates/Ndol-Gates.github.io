Kebijakan Privasi — Rekap Nota

Berlaku sejak: 23 September 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Rekap Nota ("Aplikasi") mengumpulkan, menggunakan, dan melindungi data pengguna ("Anda"). Dengan menggunakan Aplikasi, Anda menyetujui praktik yang dijelaskan di sini.

1. Data yang Dikumpulkan

  • Foto nota/struk — diambil melalui kamera perangkat Anda atas persetujuan Anda, dan disimpan secara lokal di perangkat.
  • Informasi akun Google — jika Anda memilih untuk login dengan Google, Aplikasi menerima nama, alamat email, dan foto profil dasar dari akun Google Anda untuk keperluan autentikasi.
  • Akses file Google Drive terbatas — Aplikasi menggunakan izin Google Drive dengan cakupan drive.file, yang hanya memberikan akses ke file yang dibuat atau dibuka secara spesifik melalui Aplikasi. Aplikasi tidak dapat melihat, mengubah, atau menghapus file lain di Google Drive Anda.

2. Bagaimana Data Digunakan

  • Menyimpan dan menampilkan rekap nota/struk Anda di dalam Aplikasi.
  • Menyediakan fitur login agar Anda dapat mengakses Aplikasi dengan akun Google Anda.
  • Menyimpan hasil ekspor rekap (misalnya file Excel) ke Google Drive Anda sendiri, atas permintaan Anda.

3. Penyimpanan Data

Data nota/struk disimpan secara lokal di perangkat Anda. Data tersebut tidak dikirim ke server pihak ketiga mana pun, kecuali file yang secara eksplisit Anda pilih untuk disimpan ke Google Drive Anda sendiri melalui fitur ekspor.

4. Berbagi Data

Kami tidak menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak ketiga untuk tujuan pemasaran. Data hanya diproses melalui layanan resmi Google (Google Sign-In dan Google Drive API) sesuai kebutuhan fungsi Aplikasi.

5. Keamanan

Kami menerapkan langkah-langkah wajar untuk melindungi data Anda dari akses, perubahan, atau penghapusan yang tidak sah. Namun, tidak ada metode penyimpanan atau transmisi data yang 100% aman.

6. Hak Anda

Anda dapat mencabut akses Aplikasi ke akun Google Anda kapan saja melalui halaman izin akun Google. Anda juga dapat menghapus data lokal Aplikasi dengan menghapus aplikasi dari perangkat Anda.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui dari waktu ke waktu. Perubahan akan dipublikasikan di halaman ini dengan tanggal pembaruan yang baru.
